# Норма · Бюро (127-ФЗ) — Квиз-лендинг с живым расчётом сметы

Демонстрационный проект интерактивного квиз-лендинга для юридического бюро (**«Норма · Бюро»**) по списанию долгов и банкротству физических лиц (Федеральный закон № 127-ФЗ).

- **Live Demo:** [Открыть демо](https://butorov.dev/legal-127-quiz/demo/)

---

## Ключевые возможности

- **5-шаговый квиз-калькулятор:** сумма долга (ползунок `250 000 – 5 000 000+ ₽` + быстрые чипсы), мультивыбор типов задолженностей, статус имущества, просрочки и сделки за 3 года, выбор рассрочки или единовременной оплаты.
- **Прогрессивная скидка:** на каждом шаге скидка растёт с `2%` до `10%`, при единовременной оплате добавляется `+5%`.
- **Автоопределение сценария МФЦ:** при соответствии критериям внесудебного банкротства по 127-ФЗ смета автоматически переключается на процедуру через МФЦ с `0 ₽` судебных расходов.
- **Пресеты судебной практики:** кнопка «Примерить расчёт в квизе» в карточках дел загружает параметры кейса в калькулятор и переводит на итоговую смету.
- **Модалка CRM / Webhook:** переключение между карточкой лида для Telegram/CRM и готовым `JSON-payload` с копированием в буфер обмена.
- **Безопасность:** рендер DOM через `document.createElement` и `textContent` (без `innerHTML` с пользовательским вводом), маска телефона `+7 (999) 000-00-00` и клиентская валидация.

## Локальный запуск

Для работы ES-модулей запустите любой статический HTTP-сервер из папки `legal-127-quiz/`:

```bash
python -m http.server 8080
```

После запуска откройте `http://localhost:8080` в браузере.
