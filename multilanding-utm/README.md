# ВЕКТОР · Мультилендинг с динамической подменой UTM-меток

Демонстрационный мультилендинг транспортной компании **«ВЕКТОР»** с мгновенной адаптацией заголовка, оффера, ключевых метрик, формы расчёта и выделением релевантного автопарка под рекламный трафик (`utm_term`, `utm_campaign`, `utm_source`).

🔗 **Живое демо:** [https://butorov.dev/multilanding-utm/demo/](https://butorov.dev/multilanding-utm/demo/)

## Что реализовано

- **UTM-движок (`js/utm-engine.js`)**:
  - Парсинг `URLSearchParams` и сопоставление с рекламными пресетами (`default`, `fura20`, `gazel`, `ref`, `negabarit`).
  - Поддержка кастомного `utm_term` с ограничением длины до 46 символов и защитой от XSS (`escapeHtml`, `sanitizeKeyword`, вывод через `textContent`).
  - Живое обновление URL через `window.history.replaceState` без перезагрузки страницы.
- **Интерактивная песочница и каталог автопарка (`js/ui.js`, `js/fleet-data.js`)**:
  - Переключение 5 готовых рекламных сценариев и ввод произвольного ключевого запроса.
  - Геометрические SVG-схемы техники с автоматическим выделением рекомендуемого кузова под текущий оффер.
- **Перехват UTM-контекста в заявке (`js/main.js`)**:
  - Клиентская валидация телефона и имени перед отправкой.
  - Предпросмотр JSON-пейлоада для CRM / Telegram с копированием в буфер обмена.
