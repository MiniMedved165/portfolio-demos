# BREW HAVEN — Лендинг спешелти-кофейни с предзаказом ко времени

Тёмный атмосферный промо-сайт кофейни с акцентом на фотореалистичную подачу напитков, интерактивной картой меню и модулем предзаказа к приходу гостя (с передачей уведомления бариста в Telegram).

## Стек и возможности
- Адаптивная тёмная палитра (`#120D0A`, `#C6976E`) + связка шрифтов `Cormorant Garamond` / `Onest` / `JetBrains Mono`
- Интерактивное меню напитков с переключением полноты карты и добавлением в корзину
- Модуль предзаказа ко времени («Через 10 / 15 / 30 минут») с расчётом суммы и статусом отправки
- Форма подписки на обжарку с генерацией промокода
