# KRONOS DETAIL — Промо-сайт со шторкой «До / После»

Демонстрационный промо-сайт детейлинг-студии **KRONOS DETAIL** с интерактивной шторкой сравнения фотографий **«До / После»**, привязкой шторки к прокрутке страницы и быстрой онлайн-записью по классу автомобиля.

- **Live Demo:** [Открыть демо](https://butorov.dev/promo-before-after/demo/)

---

## Ключевые возможности

- **Шторка сравнения «До / После»:** 4 тематических сценария (полировка + керамика 9H, химчистка салона, оптика + PPF, диски и суппорты) с фильтрами, процедурными оверлеями дефектов и телеметрией.
- **Scroll-Sync + ручной перехват:** шторка плавно раскрывает результат при прокрутке страницы (`84% → 16%`), а при перетаскивании (Pointer Events), нажатии пресетов (`Только «ДО»` / `50 / 50` / `Только «ПОСЛЕ»`), клавиш `ArrowLeft` / `ArrowRight` / `Home` / `End` или кнопки `Авто-демо` переключается в ручной режим.
- **Калькулятор и быстрая запись:** выбор класса авто (`Седан / Купе`, `Кроссовер`, `Внедорожник`, `Спорт / Люкс`), услуги и временного слота с мгновенным пересчётом цены.
- **Модалка CRM / Webhook:** карточка записи и готовый `JSON-payload` с копированием в буфер обмена.
