# MONOLITH — Интерактивный квиз-лендинг со сметой ремонта

Демонстрационный проект квиз-лендинга для студии архитектурного ремонта **MONOLITH** с мгновенным расчётом сметы в реальном времени, подстановкой пресетов из галереи и формированием структурированного JSON-пакета заявки для Telegram / CRM.

- **Live Demo:** [Открыть демо](https://butorov.dev/landing-quiz/demo/)

---

## Возможности демо-стенда

- **5-шаговый интерактивный квиз:** тип объекта, площадь с ползунком и быстрыми пресетами, высота потолков, стиль отделки, мультивыбор инженерных опций, сроки старта и бонус.
- **Живая смета (Live Blueprint):** мгновенный пересчёт черновых, чистовых и инженерных работ, скидки, цены за м² и ориентировочного срока реализации с плавной анимацией чисел.
- **Пресеты из галереи:** кнопка «Рассчитать похожий →» в карточках реализованных объектов автоматически подставляет параметры в калькулятор и переводит к финальной смете.
- **Готовый Webhook-payload:** после заполнения формы открывается модальное окно со структурированным JSON-пакетом заявки и кнопкой копирования в буфер обмена.
- **Безопасность:** защита от XSS при повторном рендере шагов формы (установка значений через DOM API и экранирование), клиентская валидация имени и контакта.

## Архитектура проекта

Код разделён на независимые ES-модули с чётким разделением ответственности:

```text
landing-quiz/
├── index.html          # Семантическая разметка без встроенных стилей и скриптов логики
├── css/
│   └── styles.css      # Кастомные стили, CSS-переменные, анимации и стили range-ползунка
├── js/
│   ├── config.js       # Конфигурация квиза: тарифы, коэффициенты, опции, бонусы
│   ├── calculator.js   # Чистая функция calculateEstimate() и форматирование цен
│   ├── quiz-ui.js      # Рендер шагов 1–6, live-смета, валидация и пресеты
│   └── main.js         # Точка входа: навигация, модалка, копирование JSON, Scroll Reveal
└── README.md
```

---

## Стек технологий

- **HTML5** (семантическая вёрстка, ARIA-атрибуты)
- **Tailwind CSS** (дизайн-токены и адаптивная сетка)
- **Vanilla JavaScript (ES6+ Modules)**
- **JSON Webhook Payload** (демонстрация формата интеграции с Telegram Bot API / AmoCRM / Битрикс24)

## Локальный запуск

Поскольку скрипты подключены как `type="module"`, для локального просмотра достаточно запустить любой статический HTTP-сервер из папки `landing-quiz/`:

```bash
# Python 3
python -m http.server 8080

# или Node.js
npx serve .
```

После этого откройте `http://localhost:8080` в браузере.
