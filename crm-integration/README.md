# SAYSO. · Прямая интеграция сайта с AmoCRM и Битрикс24

Демонстрационный сайт школы живого английского **«SAYSO.»** в журнальной эстетике с интерактивной консолью прямой интеграции **AmoCRM API v4** и **Битрикс24 REST API**.

🔗 **Живое демо:** [https://butorov.dev/crm-integration/demo/](https://butorov.dev/crm-integration/demo/)

## Пайплайн обработки заявки

1. **Валидация и сбор контекста**: имя, телефон / Telegram, выбранный слот времени, программа, бюджет, результат экспресс-диагностики и UTM-метки (`CHECK`).
2. **Проверка дублей контакта (`GET`)**: нормализация номера (`normalizeContactKey`) и поиск существующего контакта (`/api/v4/contacts` или `crm.duplicate.findbycomm`).
3. **Создание сделки (`POST`)**: формирование сделки с бюджетом, воронкой, тегами и кастомными полями.
4. **Авто-задача менеджеру (`POST`)**: постановка задачи методисту на выбранный гостем слот времени.
5. **Уведомление (`HOOK`)**: отправка карточки сделки в Telegram-чат.

## Интерактивные возможности

- Озвучка британских идиом через Web Speech API (`en-GB`) и переключение 4 фраз дня.
- Разворот уровней CEFR (`A1`–`B2`) с живыми диалогами и 6 карточками навыков.
- Экспресс-диагностика из 3 ситуаций с автоподстановкой уровня в форму записи.
- Консоль CRM API с переключением провайдеров **AmoCRM ↔ Битрикс24**, просмотром Request/Response JSON и кнопкой тестирования анти-дубля.
