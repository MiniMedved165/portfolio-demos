# MOTION 2026 · Онлайн-оплата (ЮKassa / СБП) и чеки 54-ФЗ

Демонстрационный сайт конференции **MOTION 2026** с песочницей приёма онлайн-платежей (**ЮKassa** / **СБП QR**), промокодами, обработкой отказа банка и автоматической генерацией фискального чека **54-ФЗ** и электронного билета.

🔗 **Живое демо:** [https://butorov.dev/online-payment/demo/](https://butorov.dev/online-payment/demo/)

## Платёжный и фискальный пайплайн

`checkout` → `3-D Secure / СБП` → `webhook payment.succeeded` → `ОФД 54-ФЗ` → `выдача билета`

- **Расчёт корзины и 54-ФЗ (`js/pricing-engine.js`)**:
  - `calculateOrderTotals()` вычисляет стоимость билетов (`1–10`), доп. опции «AI-воркшоп (+3 500 ₽)» и скидки по промокоду (`EARLY20` — −20%, `MOTION10` — −10%).
  - `buildFiscalItems()` пропорционально распределяет скидку по товарным позициям чека согласно требованиям 54-ФЗ.
- **Песочница оплаты (`js/checkout-modal.js`)**:
  - Переключение **Банковская карта (МИР / Visa / MC) ↔ СБП (QR-код)**.
  - Тестовые карты: **«✓ Одобрение (МИР)»** (`*0042`) и **«✕ Отказ банка»** (`*0002`, код ошибки 51).
  - Платёжная гигиена: номера карт и CVC никогда не сохраняются в `localStorage`/`sessionStorage`/`cookies` и не попадают в лог; в Webhook JSON используется только маскированный хвост (`MIR *0042`).
- **Чек 54-ФЗ и Webhook (`js/receipt-54fz.js`)**:
  - Формирование кассового чека (ФН, ФД, ФПД, ОФД, QR) и именного пропуска `#MTN-XXXX`.
  - Просмотр и копирование серверного события `payment.succeeded`.
